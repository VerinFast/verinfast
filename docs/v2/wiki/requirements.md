# Requirements

Requirements are written as **MUST / SHOULD / MAY**. Anything marked MUST is a
release blocker for v2.

- [[Requirements: Functional]] — what it has to measure and emit
- [[Requirements: Non-Functional]] — performance, portability, observability, testing
- [[Requirements: Embeddable Library API]] — workstream 5
- [[Requirements: ATD v3 Integration]] — workstream 4
- [[Requirements: Security & Privacy]] — the trust boundary

Traceability: every requirement below either preserves something in
[[Feature Inventory]] or fixes something in [[Known Defects & Debt]]. If it does
neither, it is scope creep and should be argued for in [[Open Questions]].
